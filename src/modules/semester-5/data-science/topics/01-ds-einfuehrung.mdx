Die Punktdarstellung auf Folie 16 zeigt **unterschiedliche Einzelwerte innerhalb beider Gruppen**. Das Balkendiagramm hier stellt ausschließlich die im Skript angegebenen **Mittelwerte** dar.

<Callout type="pitfall" title="Beobachtung ist kein endgültiger Beweis">
Die Schlafgruppe erinnert im Durchschnitt **3 Wörter mehr**. Daraus lässt sich die Frage nach einem allgemeinen Vorteil **nicht endgültig entscheiden**. Wissenschaftliche Aussagen werden kritisch überprüft und bleiben vorläufig.
</Callout>

<Card title="Die Aussage kritisch prüfen">

- Solange nicht versucht wurde, eine Aussage zu widerlegen, kann sie laut Skript keinesfalls als belegt gelten.
- Ein möglicher Prüfschritt: untersuchen, **welche Unterschiede zufällig auftreten würden, wenn es keinen Unterschied gäbe**.

</Card>

## Beobachtung mit einem Modell vergleichen

<DefinitionBox term="Modellannahme im Beispiel" source="Folien 17–18">
Für den Vergleich wird angenommen, dass es **keinen Unterschied** zwischen den Behandlungen gibt. Simulationen zeigen, welche Mittelwertdifferenzen trotzdem zufällig auftreten können.
</DefinitionBox>

<Diagram title="So werden die beobachteten Daten mit der Modellannahme verglichen" height={330} chart={`flowchart TB
  A["Modellannahme: kein Unterschied"] --> B["Zufällige Mittelwertdifferenzen simulieren"]
  B --> C["Beobachteten Unterschied von 3 Wörtern einordnen"]
`} />

Folie 18 zeigt die **Verteilung der simulierten Mittelwertdifferenzen** und markiert den empirischen Wert bei **3 Wörtern**. Entscheidend ist, wie häufig ein mindestens so großer Unterschied unter der Modellannahme auftritt.

<KpiGrid items={[
  { value: '3 Wörter', label: 'Beobachtete Mittelwertdifferenz', accent: 'accent' },
  { value: '0,0474', label: 'Simulationsanteil mit einem Unterschied von mindestens 3 Wörtern' },
]} />

<Callout type="merksatz" title="Den Anteil unter der Modellannahme lesen">
**Wenn es keinen Unterschied gibt**, ist ein beobachteter Unterschied von mindestens 3 erinnerten Wörtern im Modell eher selten. Der in den Folien genannte Anteil beträgt **0,0474**.
</Callout>
