## Beobachtung mit einem Modell vergleichen

<DefinitionBox term="Modellannahme im Beispiel" source="Folien 17–18">

</DefinitionBox>

So lässt sich das Histogramm lesen:

- Jeder Balken zählt, **wie viele Simulationen** eine Mittelwertdifferenz in dieser Klasse ergeben haben.
- Die Verteilung liegt **um 0**, denn das Modell nimmt an, dass es keinen Unterschied gibt. Trotzdem treten zufällig Differenzen von mehreren Wörtern auf.
- Die gestrichelte Linie markiert den **beobachteten Wert von 3 Wörtern**. Die orangefarbenen Ränder enthalten alle Simulationen mit einer Differenz von **mindestens 3 Wörtern**, auf beiden Seiten.

<Callout type="merksatz" title="Den Anteil unter der Modellannahme lesen">
**Wenn es keinen Unterschied gibt**, haben nur **0,0474** der Simulationen, also knapp 5 %, eine Differenz von mindestens 3 erinnerten Wörtern. Der beobachtete Unterschied ist im Modell deshalb **eher selten**.
</Callout>
