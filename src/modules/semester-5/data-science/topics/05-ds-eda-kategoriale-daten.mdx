## Grafiken und Häufigkeiten im Überblick

<Columns count={2}>
<Card title="Grafiken" tone="accent">

- **Säulendiagramm / Balkendiagramm:** Häufigkeit von Merkmalsausprägungen (nominal, ordinal, metrisch diskret). Vertikal: **Säulendiagramm**; horizontal: **Balkendiagramm**.
- **Mosaikplot:** Darstellung der Merkmalsausprägungen **zweier nominaler Merkmale**.

</Card>

### Säulendiagramm

Ein Säulendiagramm visualisiert die **absoluten oder relativen Häufigkeiten** von Beobachtungen kategorialer (oder metrisch diskreter) Variablen **durch die Höhe der Säulen**. Es wird häufig auch Balkendiagramm genannt – korrekterweise hat ein Balkendiagramm aber **querliegende Balken**.

## Eine Variable: Säulendiagramm, Anteil, Tabelle

Wer zahlt die Rechnung? Drei Wege, dieselbe Variable `sex` zu analysieren:

```r
gf_bar( ~ sex,       # (unabhängige) Variable, die analysiert wird
        data = tips) # Datensatz
```

<Exercise title="Geschlecht RechnungszahlerIn" question="Analysiert über das Säulendiagramm oben: Welche Aussage stimmt?" options={['Bei einer Mehrheit der Stichprobe zahlt eine Frau.', 'Bei einer Mehrheit der Stichprobe zahlt ein Mann.', 'Weiß nicht.']} answer={1}>

Die Säule für **Male** ist deutlich höher. Die Tabellierung auf Folie 118 bestätigt das: **157 Männer** gegenüber **87 Frauen**, also rund **64 %** Männer.

</Exercise>

### Säulen- oder Balkendiagramm

```r
# Zwei Plots erzeugen
plot1 <- gf_bar( ~ sex, data = tips)
plot2 <- gf_barh( ~ sex, data = tips)
# Nebeneinander anzeigen
grid.arrange(plot1, plot2, nrow = 1)
```

Folie 116 zeigt beide Plots nebeneinander: links **vertikale Säulen** (`gf_bar`), rechts **horizontale Balken** (`gf_barh`) mit `count` auf der x-Achse.

### Anteil p

```r
prop( ~ sex,               # (unabhängige) Variable, die analysiert wird
      success = "Female",  # wovon den Anteil bestimmen
      data = tips)         # Datensatz
```

```text
prop_Female
  0.3565574
```

## Bedingte Analyse: Geschlecht nach Tageszeit

<Exercise title="Modellierung Geschlecht" question="Das Geschlecht des Rechnungszahlenden (sex) variiert: Mal zahlt ein Mann, mal zahlt eine Frau. Welche der anderen Variablen könnte einen Teil dieser Variation modellieren, d. h., womit könnte dies zusammenhängen?">

Hier ist **vieles möglich** – im Folgenden wird es mit der **Tageszeit** `time` versucht → Geschlecht des Rechnungszahlenden **je Tageszeit**.

</Exercise>

```r
gf_bar( ~ sex     # Variable, die analysiert wird
        | time,   # Variable, nach der bedingt wird
        data = tips)
```

<Card title="Exkurs: Farben mit fill" tone="neutral">

```r

Die Farbgebung kann sich auch auf eine **weitere Variable** beziehen: Mit `fill = ~smoker` zeigen die Säulen auf Folie 123 zusätzlich den **Raucheranteil** (gestapelte Farbsegmente No / Yes).

## Kreuztabellen richtig lesen

<Exercise title="Raucher je Wochentag" question="Welcher Befehl führt eine Kreuztabellierung der Anteile der Raucher je Wochentag durch?" options={['tally( ~ smoker | day, format = "proportion", data = tips)', 'tally( ~ day | smoker, format = "proportion", data = tips)']} answer={0}>

**a)** ist korrekt. In dieser Reihenfolge werden **zeilenweise** die Ausprägungen von `smoker` und **spaltenweise** die Ausprägungen von `day` dargestellt – grundsätzliche Formeleingabe $y \sim x \mid z$, hier `smoker` gruppiert nach `day`. Mit `format = "proportion"` werden die Anteile **bezogen auf die jeweilige Spalte** berechnet.

</Exercise>

<Columns count={2}>
<Card title="tally( ~ smoker | day, …)" tone="accent">

   Yes 0.7894737 0.4827586 0.2500000 0.2741935
```

Je **Tag** summieren sich die Anteile zu 1: Wie viele Tische **an diesem Tag** sind Rauchertische?

<Callout type="pitfall" title="Confusion of the inverse">
**Wovon wird die relative Häufigkeit angegeben?**

- Der relative **Anteil der Raucher am Freitag** (0,79) entspricht **nicht** dem relativen **Anteil des Freitags an den Rauchern** (0,16).
- Der Papst ist ein Mann, aber nur die allerwenigsten Männer sind Papst.
- Die Wahrscheinlichkeit, **krank** zu sein, wenn das **Testergebnis positiv** ist, ist nicht dasselbe wie die Wahrscheinlichkeit, dass das **Testergebnis positiv** ist, wenn man **krank** ist.
</Callout>

<p className="text-xs text-muted-foreground">Rückgerechnet aus den beiden Tabellen (Ergänzung): Freitag 4 Nichtraucher- und 15 Rauchertische (19), Samstag 45 / 42 (87), Sonntag 57 / 19 (76), Donnerstag 45 / 17 (62); insgesamt 151 Nichtraucher- und 93 Rauchertische. Der hohe Raucheranteil am Freitag beruht also auf nur 19 Tischen.</p>

## Typische R-Fehler

<Exercise title="R Fehler I" question={'Was ist an diesem Befehl falsch?  tally( ~ x data = daten)'} options={['Es fehlt eine Option.', 'Es fehlt eine bedingende Variable.', 'Es fehlt ein Komma.', 'Gar nichts.']} answer={2}>

**c)** ist korrekt, es fehlt ein Komma. Korrekt ist:

```r
tally( ~ x, data = daten)
```

</Exercise>

<Exercise title="R Fehler II" question={'Was ist an diesem Befehl falsch?  Tally( ~ x, data = daten)'}>

R unterscheidet zwischen **Groß- und Kleinschreibung** – `Tally` gibt es nicht. Korrekt muss es heißen:

```r
tally( ~ x, data = daten)
```

</Exercise>

## Mosaikplot

Ein Mosaikplot visualisiert die **gemeinsame Verteilung von zwei kategorialen Variablen**. Dabei entsprechen **Höhe und Breite** der Rechtecke der jeweiligen **relativen Häufigkeit**.

Folie 135 zeigt das **Überleben auf der Titanic** nach Klasse (1st, 2nd, 3rd, Crew): Die **Breite** einer Säule steht für den Anteil der Klasse, die **Höhe** der Rechtecke für den Anteil der Überlebenden (Yes) bzw. Nicht-Überlebenden (No) in dieser Klasse.

<DataChart type="bar" title="Überleben auf der Titanic: Anteile je Klasse laut Mosaikplot" source="Folien 135–137 · Flächen aus der Folie abgelesen, gerundet" height={280} stacked xKey="klasse" yLabel="Anteil in %" yDomain={[0, 100]} data={[

]} series={[
  { key: 'yes', name: 'Survived = Yes', color: 'var(--color-module-orange)' },
  { key: 'no', name: 'Survived = No', color: 'var(--color-module-blue)' },
]} />

<Exercise title="Mosaikplot" question="Stimmt die Aussage: Der Anteil der Überlebenden ist in der 1. Klasse größer als in den unteren Klassen?" options={['Ja.', 'Nein.']} answer={0}>

**Ja**, da der **Flächenanteil für Yes** in der 1. Klasse **relativ größer** ist als in den anderen Klassen.

</Exercise>

<p className="text-xs text-muted-foreground">Hinweis zur Darstellung: Das Diagramm zeigt nur die Höhen (Anteile innerhalb jeder Klasse). Die Breiten des Mosaikplots – der Anteil jeder Klasse an allen Personen – nehmen auf der Folie von der 1. Klasse bis zur Crew zu; die Crew ist die größte Gruppe.</p>

### Mosaikplot für Raucher und Tage

```r
mosaicplot(day ~ smoker, data = tips, color = TRUE)
```

<Callout type="warn" title="Achsen vertauscht">
Bei `mosaicplot()` werden in der Formel die Achsen vertauscht, also **`x ~ y`** – anders als bei den mosaic-Befehlen (`y ~ x`).
</Callout>

Folie 138 zeigt das Ergebnis: Je Wochentag eine Säule, deren **Breite** der Zahl der Tische entspricht (Freitag ist am schmalsten) und deren **Höhen** die Anteile No / Yes aus der Kreuztabelle oben zeigen.

<Card title="Exkurs: Farben mit viridis" tone="neutral">

```r
install.packages("viridis")
library(viridis)
mosaicplot(day ~ smoker, data = tips, color = viridis(2, alpha = 0.7))
```

</Card>
